# GOROD.RU-STUDIO
GOROD.RU Studio — платформа для анализа и проектирования городской среды. Изучайте улицы, здания и парки на карте, измеряйте площади, создавайте зоны анализа и разрабатывайте градостроительные концепции. Сохраняйте проекты, редактируйте объекты и используйте AI-помощника. Исследуйте город, анализируйте пространство и создавайте среду будущего сами!
